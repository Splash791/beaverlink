# AGENTS.md

BeaverLink recommends who OSU students and alumni should meet at events. Workflow rules are in [CONTRIBUTING.md](CONTRIBUTING.md).

- Write readable, maintainable code that matches existing code convention.
- Comments should be brief and not large blocks of text. 
- Use fake seed data only in development. Profiles are real people's personal data.
- Stack: FastAPI backend in `backend/` (scaffold only). Setup and commands are in README.md.
- Recent commits are concise and often use Conventional prefixes such as `chore:`. Keep PRs scoped and include verification. Never merge a PR without explicit user permission; stop after pushing and creating the PR until the user says "merge it" or equivalent.
- Read docs/requirements.md, docs/design.md, and docs/risks.md before changing behavior, and update them in the same PR when the code changes.
